# Mods PokeIsland By NopziTV

Mods client Fabric 1.21.1 pour le serveur PokeIsland (Cobblemon).

## Installation
1. Télécharge les jars dans l'onglet Releases (à droite de cette page).
2. Mets-les dans le dossier mods de ton jeu.
3. Si tu avais une ancienne version d'un mod, supprime d'abord l'ancien jar.

## Les mods
- **Outils PokeIsland By NopziTV** : tri du PC, recherche, Pokédex Manquants, menu des coffres privés (/pv), équipe personnalisée
- **Pêche PokeIsland By NopziTV** : HUD de pêche et HUD tournoi
- **Quêtes PokeIsland By NopziTV** : écran des missions, suivi et bouton Quêtes
- **Gestion HUD By NopziTV** : déplace tous les éléments d'interface avec la touche pavé 0

## Raccourcis
- Pavé 0 : déplacer les éléments
- Pavé 1 : /pv 1
- J : missions
